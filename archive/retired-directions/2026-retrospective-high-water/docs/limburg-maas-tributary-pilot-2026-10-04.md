# Maas–tributary information-value pilot (internal research aid, 2026-10-04)

## Question and design

Could the six held tributary gauges add useful information about elevated Maas discharge at Venlo beyond upstream Maas discharge at Sint Pieter and observed rainfall in the six tributary catchments? This is a retrospective information-value test, **not** an operational forecast replay, a causal estimate of tributary contributions, or dissertation prose. It does not replace the chapter's existing analysis.

The fixed exploratory design uses rain-spell hour six and then 24-hour updates while that spell continues, with a 72-hour Venlo target. The baseline has Sint Pieter's lagged discharge level and 6/24-hour rises, six-hour regional rainfall maximum and wet-catchment count, and season. The comparison adds only a count of six tributaries above their historical p90 and the highest tributary percentile. Regularized logistic fits train on earlier calendar years and test 2020–2024 one year at a time. Gauge percentiles and the Venlo p90 target are fixed from 2017–2019. These are research thresholds, not official flood-warning levels. The 2017–2024 window avoids Venlo's mostly nonstandard quality-coded 2010–2015 discharge archive. Predictors use flow observations at least one hour before each issue time.

## Critical source-data finding

The old `data/interim/rws_maas_hourly.csv` silently mixed RWS quality codes, methods, and daily values; do not use it for this comparison. The new runner reads raw annual JSON, selects the long high-frequency F103 blocks, removes daily summaries and duplicate annual endpoints, retains source-code counts, and requires at least four valid 10-minute readings per hourly bin. The primary test uses only controlled quality-code `00` readings. RWS says Waterinfo displays codes `00, 10, 20, 25, 30, 40`; it also describes code `25` as interpolation in both space and time. Thus the strict primary screen is narrower than Waterinfo's display rule. See [RWS WaterWebservices guidance](https://rijkswaterstaatdata.nl/projecten/waterwebservices-overschakeling/) and [RWS bulk attribute guide](https://rijkswaterstaatdata.nl/publish/pages/244515/uitleg-attributen-bij-bulkwaarnemingenservice-dd-06-11-2023-.pdf).

Venlo's July 12–20, 2021 ten-minute discharge values are almost entirely code `25` (144 values per day in the held file). The apparent July 2021 Venlo discharge wave in the permissive screen is therefore largely interpolated. The strict primary analysis does **not** evaluate the principal July 2021 Venlo rise. A stage record might resolve that particular event in a later, separately justified study; it is not a requirement created by this pilot. RWS code `00` coverage is about 87% at Sint Pieter and 95% at Venlo for 2017–2024; the complete 72-hour target requirement reduces eligible decisions, especially in 2023.

## Pilot result

The strict screen has 147 forward-test decision times from 132 rain spells, including 27 positive Venlo p90 outcomes. It includes 27 decisions in 2020, 33 in 2021, 26 in 2022, 9 in 2023, and 52 in 2024. The baseline Brier score is 0.1279; adding the tributary summaries worsens it to 0.1299. Log loss worsens from 0.4523 to 0.4722, average precision falls from 0.561 to 0.551, and AUC falls from 0.792 to 0.775. The added-minus-baseline pattern is small relative to sampling variation, and 2024 supplies 18 of the 27 positives. A 999-draw year-resampling diagnostic gives baseline-minus-added Brier change -0.0020 (2.5–97.5% range -0.0045 to 0.0001) and log-loss change -0.0199 (-0.0355 to -0.0024). With only five test years, these ranges are exploratory, not definitive confidence intervals.

An earlier permissive run using all Waterinfo-displayed codes (including interpolated `25`) had 173 test decisions and 38 positives. It also showed no added value: Brier 0.1210 baseline versus 0.1220 with tributaries; log loss 0.4103 versus 0.4344. Its apparent July 2021 evaluation is not measurement-clean, so it is sensitivity context only.

The narrow conclusion is that **these two coarse tributary summaries did not add useful signal to this specific retrospective Venlo p90 task**. This does not establish that tributaries never matter for Maas warning or local compound flooding. The geography, incomplete tributary coverage, a rainfall trigger limited to the six local catchments, code-00 omissions, and the interpolation of Venlo's July 2021 discharge all limit that inference. One monitored stream (Voer) enters the Maas above Sint Pieter, so some of its signal is already in the upstream gauge. A confluence study would require a different spatial target and water-level evidence. Published work on a separate lowland Maas confluence finds that wave duration and joint timing, rather than isolated peak order, can matter for local levels: [Geertsema et al. 2018](https://hess.copernicus.org/articles/22/5599/2018/).

## Reproduction and disposition

Run `python scripts/62_test_maas_tributary_increment.py` in the chapter environment. The ignored `results/event_study/maas_tributary_increment_v1/` directory contains input hashes, source-code counts by year, cleaned hourly Maas discharge, decisions, forward-year predictions, scores, and year-resampling draws. The script fixes the model, features, target, and random seed. The code and this memo preserve the negative result. Do not present this as the chapter's finding or add more models/features merely to rescue it. A new question about mainstem–tributary coincidence should be designed around a specific confluence and validated stage records, if pursued.
