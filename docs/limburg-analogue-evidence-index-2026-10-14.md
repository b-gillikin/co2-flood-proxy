## Errors versus exploratory refinement

No audited basis currently establishes that mean pooling or the original
AlphaEarth comparison was numerically invalid. Do not label those results
incorrect merely because later representations perform better. The consistency
audit records corrected replay fingerprints, removed unused weather eligibility
(with no cohort/result change), and clarified metric meanings. Those fixes do
not invalidate every earlier empirical result.

If a genuine implementation/alignment/evaluation error is later found, record
its affected run IDs, correction and replacement; exclude affected values from
scientific conclusions while preserving their provenance. That rule is distinct
from retaining valid ablations or different-cohort sensitivities.

Representations, outcomes and archive handling were refined after inspecting
results. The latest analyses remain exploratory; neither archiving earlier work
nor using the latest corrected workflow creates preregistration, an untouched
test set or independent confirmatory evidence. Conditional sampling intervals
do not account for the full development process, reused donors, measurement
uncertainty or multiple comparisons. Preserve unfavorable results and reasons
for changes; do not select a headline configuration solely for its best score.
